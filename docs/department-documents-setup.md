# หน้าแยกตามหน่วยงาน

พัฒนาตาม `แยกตามหน่วยงาน.md` โดยเลือกประเภทงาน → หลักสูตร → ตัวกรองของแต่ละงาน ข้อมูลตัวเลือกทั้งหมดอ่านจากฐานข้อมูล และกรอบเกณฑ์อ่านจากความสัมพันธ์ของหลักสูตร

| ประเภทงาน | ตัวกรอง | เอกสาร |
| --- | --- | --- |
| งานประกันคุณภาพ (`QA`) — WFME | ปีการศึกษา | SAR, หนังสือรับรองหลักสูตรจากแพทยสภา, Annual Progress Report, รายงานผลการพิจารณา APR |
| งานประกันคุณภาพ (`QA`) — AUN | ปีการศึกษา | SAR, CAR |
| งานบริหารหลักสูตร (`CM`) | ฉบับหลักสูตร | เอกสารหลักสูตรใหม่หรือฉบับปรับปรุง |
| งานจัดการเรียนการสอน (`TCH`) | ปีการศึกษา, ภาคการศึกษา, ชั้นปี, รายวิชา | มคอ.3, มคอ.5, ผลประเมิน |
| งานวัดและประเมินผล (`ASM`) | ปีการศึกษา, ภาคการศึกษา, ชั้นปี, รายวิชา | ผลการศึกษา |
| งานรับเข้า (`ADM`) | ปีการศึกษา | ประกาศการรับสมัคร |

งานอื่นและหน่วยงานที่ไม่มีงานย่อยใช้รายการเอกสารคุณภาพเดิม กรองตามหน่วยงานและหลักสูตร

## โครงสร้างข้อมูล

- `docs_academic_years`: ปีการศึกษา พ.ศ.
- `docs_semesters`: ภาคการศึกษาและลำดับการแสดง
- `docs_study_years`: ชั้นปี
- `docs_curriculum_versions`: ฉบับหลักสูตร แยกตาม `program_id` และปี พ.ศ.
- `docs_courses`: รายวิชา แยกตาม `program_id` และรหัสวิชา
- `docs_course_offerings`: รายวิชาที่เปิดสอนในปีการศึกษา ภาคการศึกษา และชั้นปีที่กำหนด
- `docs_work_documents`: เอกสารตามประเภทงาน ผูกหน่วยงาน งานย่อย หลักสูตร และปี/ฉบับหลักสูตร/การเปิดสอน

เอกสารประเภทนี้แยกจาก `docs_qa_documents` ซึ่งเป็นทะเบียนเอกสารคุณภาพที่ออกรหัสและผูกเกณฑ์ประเมิน

หน้า **ตั้งค่าข้อมูลพื้นฐาน → ภาพรวมการตั้งค่า** แบ่งเป็น 4 หมวด มีช่องค้นหาและจำนวนรายการของแต่ละข้อมูล:

- **หน่วยงานและงานย่อย**: หน่วยงานหลัก งานย่อยและประเภทงาน
- **หลักสูตรและรายวิชา**: หลักสูตร ฉบับหลักสูตร รายวิชา การเปิดสอนรายวิชา
- **ปีและภาคการศึกษา**: ปีการศึกษา ภาคการศึกษา ชั้นปี
- **เอกสารและเกณฑ์ประเมิน**: กรอบเกณฑ์การประเมิน โครงสร้างเกณฑ์ ระดับเอกสารคุณภาพ

เมื่อต้องการเพิ่มรายวิชา ให้เปิดหมวด **หลักสูตรและรายวิชา → รายวิชา** แล้วผูกปี ภาคเรียน และชั้นปีที่ **การเปิดสอนรายวิชา** รายวิชาจะปรากฏเฉพาะหลักสูตรและตัวกรองที่ตรงกัน

## Migration และข้อมูลเริ่มต้น

Migration: `prisma/migrations/20261021020000_add_department_work_documents/migration.sql`

Migration `20261021030000_add_document_workflow` เพิ่ม `docs_sub_departments.document_workflow` เพื่อเลือกรูปแบบเอกสารแยกจากรหัสงาน ผู้ดูแลเปลี่ยนรหัส เช่น `CM` เป็น `CMU` ได้โดยรูปแบบเอกสารยังเหมือนเดิม เลือกหรือเปลี่ยนรูปแบบได้ที่ **ตั้งค่าข้อมูลพื้นฐาน → หน่วยงานและงานย่อย → งานย่อยและประเภทงาน → รูปแบบเอกสาร** ถ้าไม่เลือกจะใช้เอกสารคุณภาพทั่วไป

```powershell
node node_modules/prisma/build/index.js migrate deploy
node node_modules/prisma/build/index.js generate
node prisma/seed-department-documents.mjs
```

Seed เฉพาะส่วนนี้เพิ่มข้อมูลที่ขาด โดยไม่รีเซ็ตรหัสผ่านหรือแก้ค่าที่มีอยู่:

- ปีการศึกษา 2569
- ภาคการศึกษาที่ 1, 2 และภาคฤดูร้อน
- ชั้นปี 1–6 (ชั้นปีของแต่ละรายวิชากำหนดผ่านการเปิดสอน)
- M.D.: หลักสูตรใหม่ 2553, ฉบับปรับปรุง 2565 และ 2570
- B.PMD.: หลักสูตรใหม่ 2553, ฉบับปรับปรุง 2559, 2564 และ 2569
- งาน `QA` และ `CM` ภายใต้ `EDU` ถ้ายังไม่มี

ไม่มีการเพิ่มรายวิชาสมมติหรือไฟล์เอกสารตัวอย่าง ต้องเพิ่มข้อมูลจริงผ่านหน้าตั้งค่า ส่วนการ seed ทั้งระบบใน `prisma/seed.ts` เรียกใช้ seed ส่วนนี้ด้วย

## ไฟล์และสิทธิ์

ผู้เข้าสู่ระบบเพิ่มเอกสารได้ตามรูปแบบการจัดการเอกสารเดิมของระบบ ไฟล์รองรับ PDF, Word, Excel ขนาดสูงสุด 20 MB และเก็บใน `public/uploads/work-documents` โดยใช้ชื่อ UUID ผู้เพิ่มเอกสารและผู้ดูแลระบบลบเอกสารได้

ตรวจความสัมพันธ์และสถานะเปิดใช้งานที่ server ทุกครั้ง ป้องกันการจับคู่ปี หลักสูตร ฉบับหลักสูตร และรายวิชาข้ามกัน รวมถึงการส่งประเภทเอกสารผิดกรอบเกณฑ์ การย้ายข้อมูลหลักที่มีเอกสารอ้างอิงไปยังหลักสูตรหรือการเปิดสอนอื่นจะถูกปฏิเสธ
